# Use case
## Company Background
- Healthcare SaaS specialising in operational platforms and products for Telehealth companies and other service providers for B2C and B2B contexts including sporting clubs, mining organisations, and workplace drug testing agencies.

# Agent specs
- Customer service specialist agent

# Features
- customisable conversation output
- search customer information with approval workflow
- save customer preferences with agentcore memory
- query mock knowledge base to answer company questions
- escalate to an internal human for use cases including:
    - emergency requests
    - service cancellations
    - requests involving children
- when human staff are not available, have an escalation become a ticket and triage/backlog with flagged priority and other properties from the request.
